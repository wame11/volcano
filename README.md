# The Civic Ledger

A small static website of plain-English explainers about how British elections and Parliament work.

The site is intended for civic-education use: sixth-form politics classes, adult learners and anyone who wants a clear description of the rules without party spin. All content is written to be politically neutral and is checked against primary sources (Electoral Commission guidance, House of Commons Library briefings and the legislation itself).

## Contents

- `index.html` – homepage with featured explainers and the reading order
- `articles/` – individual explainer articles
- `assets/css/site.css` – stylesheet (light and dark themes)
- `assets/js/site.js` – small progressive enhancements (theme toggle, reading time)
- `assets/img/` – illustrations as SVG

## Hosting

The site is plain HTML, CSS and JavaScript with no build step. It can be served from GitHub Pages or any static host: enable Pages for the repository and point it at the root of the default branch.

## Editorial notes

- Facts that are in the process of changing (for example the voting age) are described cautiously rather than assumed.
- Dates and figures are given with their source in the note at the end of each article.
- Corrections are welcome by pull request.
